# Лицензии кода, данных и карт

Статус: спецификация Этапа 0. Этот документ фиксирует текущие сведения и открытые решения, но не меняет лицензионные файлы репозитория.

## 1. Код

В репозитории сейчас есть файл `LICENSE` с лицензией MIT. План предлагает рассмотреть GPL-3.0, чтобы форки оставались открытыми, и прямо оставляет выбор за владельцем проекта. Поэтому лицензия проекта не меняется этим документом; перед сменой необходимо отдельное явное решение и проверка прав на уже существующий код и вклад каждого автора.

Новые зависимости должны проверяться на совместимость с выбранной лицензией. Лицензии и уведомления зависимостей должны сохраняться в дистрибутивах.

- [LeakCanary 2.14](https://github.com/square/leakcanary) — Apache-2.0; используется только как `debugImplementation` для диагностики удерживаемых Android-компонентов, не включается в release-вариант.

## 2. Данные и источники

- OpenStreetMap: соблюдать ODbL, показывать требуемую атрибуцию и условия производных баз.
- WiGLE: в рамках плана — только личный локальный импорт/экспорт пользователем; не превращать это в централизованное распространение или встроенную копию базы без отдельной проверки прав.
- DEM (SRTM/Copernicus GLO-30): перед распространением пакетов проверить лицензию конкретного набора, требуемую атрибуцию и ограничения выбранной версии.
- BeaconDB: учитывать условия API и не выполнять отправку вкладов; согласие на сетевой запрос не заменяет проверки условий использования.
- DBC-профили из opendbc и прочие автомобильные данные: сохранять лицензии оригинала и проверять возможность включения в распространяемые профили.

## 3. Релизы

Перед публикацией релиза формируется перечень сторонних компонентов и наборов данных с версиями, лицензиями и атрибуцией. Наличие открытого доступа к данным само по себе не означает разрешение переупаковать и распространять их в APK или архиве.
