# Матрица источников позиции и доверия

Статус: спецификация Этапа 0. Источники независимы по жизненному циклу: сбой одного отключает только его. Источник без пригодных данных не должен заставлять приложение угадывать координату.

| Источник | Роль | Ограничения и обработка |
|---|---|---|
| Сырые GNSS `Gnss*` | Основная спутниковая оценка и вход детектора | Детектору передаются сырые измерения, не системный `Location`; отсутствующие raw-поля нейтральны |
| Android network-location | Независимая кросс-проверка, только если она не является собственной mock-оценкой | Нельзя передавать её напрямую как сырые GNSS-данные; происхождение и время должны быть известны |
| Локальные Wi-Fi-точки и fingerprints | Позиционирование по совпадениям с ранее записанными координатными наблюдениями | RSSI зависит от устройства и среды; мобильные/перемещаемые точки фильтруются; без достаточных совпадений позиция не объявляется достоверной |
| Сотовые ячейки | Грубый якорь и независимая кросс-проверка | Идентификаторы доступны не на всех устройствах; соты сами по себе не дают точных координат; координаты сетевой базы требуют метаданных происхождения |
| BLE-маяки | Дополнительная радиопозиция по стабильным маякам | Случайные адреса отбрасываются; используются стабильные iBeacon/Eddystone-маяки |
| IMU телефона | Счисление пути и проверка физической согласованности | Ошибка накапливается; ориентация телефона/автомобиля должна быть учтена |
| OBD-II | Скорость/движение, проверка согласованности и помощь счислению пути | Сама скорость не задаёт координаты; PID и транспорт могут отсутствовать; ошибки не должны рушить позицию |
| Барометр | Относительные изменения высоты и кросс-проверка | Абсолютное давление дрейфует с погодой; нужна калибровка |
| DEM (SRTM/Copernicus GLO-30) | Офлайн-сопоставление высоты | Высота относительно среднего уровня моря; допуск учитывает ошибку DEM и GNSS |
| BeaconDB | Экспериментальная подсказка по онлайн-геолокации | Выключен по умолчанию, явное согласие, только чтение, отдельный источник, не эталон для обучения; онлайн-данные не должны незаметно попадать в локальные обучающие координаты |
| Ручной ориентир | Грубый запасной вариант | Только явное включение; видимый статус «грубый запасной»; не скрывает отсутствие достоверных сенсорных данных |

## Приоритет и конфликт

При выборе итоговой позиции учитываются независимость источников, возраст измерений, reported accuracy / ковариация, доступность сенсора и текущее доверие. Детали слияния и переходов находятся в ядре fusion и TrustEngine, а не в драйвере конкретного источника.

При конфликте GNSS и радио/физики доверие к GNSS пересматривается; нельзя автоматически считать GNSS истинным только потому, что он доступен. Если ни один источник не прошёл критерии пригодности, публикация прекращается.

## BeaconDB: граница текущего контракта

План требует отключённый по умолчанию экспериментальный запрос, отдельное согласие и отсутствие отправки вкладов. В текущем README Clear GPS описан cell-only запрос, тогда как обзорная часть плана упоминает отправку BSSID/RSSI. До изменения сетевого клиента это расхождение должно быть явно проверено; поле запроса нельзя расширять без отдельного решения о согласии и приватности. Эта спецификация не утверждает, что два описания уже согласованы.
