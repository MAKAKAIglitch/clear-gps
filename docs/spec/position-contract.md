# Контракт позиции Clear GPS

Статус: спецификация Этапа 0. Это целевое соглашение между источниками данных, fusion, фильтром доверия и публикацией mock-location. Оно не утверждает, что все поля уже реализованы.

## 1. Модель `PositionFix`

Одна оценка положения переносит координаты и всю информацию, нужную для оценки её пригодности.

| Поле | Смысл |
|---|---|
| `latitude`, `longitude` | Широта и долгота WGS84 в градусах |
| `altitudeMeters` | Необязательная высота; всегда вместе с типом высоты |
| `altitudeReference` | `ELLIPSOID` либо `MEAN_SEA_LEVEL`; неизвестная система не должна угадываться |
| `horizontalAccuracyMeters` | Оценка горизонтальной погрешности в метрах |
| `verticalAccuracyMeters` | Необязательная оценка вертикальной погрешности |
| `speedMetersPerSecond` | Необязательная скорость |
| `bearingDegrees` | Необязательный курс в диапазоне 0–360° |
| `wallTimeMillis` | Время UTC для журналов и отображения |
| `elapsedRealtimeNanos` | Монотонная метка времени измерения на текущей загрузке устройства |
| `source` | Источник оценки: GNSS, RADIO, FUSED, DEAD_RECKONING или MANUAL_REFERENCE |
| `trustState` | Текущее состояние доверия |
| `riskLevel` | Уровень риска, не откалиброванная вероятность |
| `qualityFlags` | Признаки доступности / отсутствия датчиков и ограничений источника |

Скорость, курс, высота и их погрешности могут отсутствовать. Отсутствующее значение не заменяется нулём. OBD, IMU и барометр сами по себе не являются координатой: это вспомогательные измерения для счисления пути, fusion или проверки доверия.

## 2. Системы координат и время

- Внешние координаты хранятся в WGS84.
- Fusion/EKF работает в локальной ENU-системе; преобразования выполняются на границе модуля.
- Высота GNSS над эллипсоидом не сравнивается напрямую с DEM, заданной относительно среднего уровня моря. На API 34+ используется `getMslAltitudeMeters()`, если доступно; на более старых версиях для перевода используется офлайн-геоид EGM.
- Для измерений GNSS, сенсоров, радио и OBD сохраняется монотонное время измерения. Время получения Bluetooth/Wi-Fi/OBD-пакета не считается автоматически временем самого измерения.
- `elapsedRealtimeNanos` сравнивается только в рамках одной загрузки устройства. Для внешних журналов дополнительно сохраняется wall-clock time.

## 3. Состояния доверия

Состояния детектора: `NORMAL`, `SUSPECT`, `SPOOFED`, `JAMMING`, `DEGRADED`. Начальные пороги риска из плана — NORMAL ниже 30, SUSPECT от 30 до 70, SPOOFED выше 70 — являются исходными границами для калибровки, а не обещанием вероятности. Гистерезис и минимальное время состояния описываются в `trust-model.md`.

Уровень риска в интерфейсе до калибровки на записях обозначается именно как риск, не как «вероятность спуфинга в процентах».

## 4. Пригодность к публикации

- Детектор GNSS получает сырые `Gnss*`-callback-и. Системный `Location` не подаётся обратно в детектор: иначе он может принять собственную mock-позицию за независимое измерение.
- Источник ошибки или отсутствующий датчик не делают остальные источники недействительными автоматически.
- При ненадёжном GNSS приложение по умолчанию использует радио и счисление пути, с настраиваемым поведением.
- При состоянии SPOOFED доверенная позиция берётся из доступных независимых источников, например радио + dead reckoning. Если доверенной позиции нет, публикация останавливается, а не продолжает выдавать старые координаты как свежие.
- В режиме «Только радио» GNSS не запрашивается приложением; координата должна опираться на пригодные совпадения с локальными радиоданными.
- Ручной ориентир не является автоматически измеренным fix: он доступен только при явном включении, маркируется как грубый запасной вариант и не маскируется под точный результат сенсоров.
- Кандидат с невалидными координатами или непригодными метками времени не публикуется. Точность всегда передаётся вместе с координатой; она не является гарантией реальной ошибки.

## 5. Разделение ответственности

Источники поставляют временные измерения; fusion формирует оценку; TrustEngine оценивает согласованность и доверие; единый MockPublisher решает, можно ли публиковать полученную оценку и через какие Android-провайдеры. Политика выбора источника не должна быть скрытой побочной логикой внутри одного сенсорного драйвера.
