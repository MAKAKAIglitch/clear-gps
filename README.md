# Clear GPS

Android-приложение для исследования GPS/GNSS-аномалий и коррекции местоположения в отмеченных пользователем зонах.

## Starter project

Полный стартовый Android-проект и Windows-сборщик находятся в архиве [ClearGPS-Windows-Starter.zip](./ClearGPS-Windows-Starter.zip). Архив содержит исходники приложения, Gradle-конфигурацию, ресурсы RU/EN, тесты геометрии зоны и скрипты сборки для Windows.

### Сборка на Windows

1. Скачайте или клонируйте репозиторий.
2. Распакуйте `ClearGPS-Windows-Starter.zip`.
3. Откройте папку `clear-gps-starter`.
4. Установите Android Studio с Android SDK Platform 36 и запустите `build-apk.bat`.

При первой сборке необходим интернет для загрузки Gradle и библиотек. APK появится в `dist/ClearGPS-debug.apk`.

## Текущий scope

- OpenStreetMap используется как картографическая основа для пользовательских зон, а не как самостоятельный источник координат.
- Начальные прозрачные правила фильтрации и оценка риска GNSS-аномалий.
- Подготовлен отдельный mock-location выход, выключенный по умолчанию.
- Wi-Fi fingerprinting, BLE-маяки, cellular positioning и полноценная sensor fusion остаются будущими этапами.

## Важные ограничения

Обычное Android-приложение не может гарантированно восстановить настоящие координаты только по факту спуфинга. Без независимого источника возможна лишь ограниченная оценка от последней доверенной позиции, с нарастающей неопределённостью. Mock location требует явного выбора пользователем в настройках разработчика; некоторые приложения могут обнаруживать или игнорировать такие координаты.
