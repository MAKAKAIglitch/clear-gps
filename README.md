# Clear GPS

Clear GPS — экспериментальное Android-приложение для выявления GNSS-аномалий и коррекции координат в пользовательских зонах риска.

## Уже включено в стартовую основу

- MapLibre Native и растровая карта OpenStreetMap.
- Ручное рисование одной полигональной зоны риска, локальное сохранение и повторная отрисовка.
- Первый прозрачный фильтр: скачки координат, неправдоподобная скорость, расхождение GNSS с сетевым местоположением и fallback.
- Foreground service с уведомлением для фонового мониторинга.
- Отдельный mock-location output, который выключен по умолчанию.
- Windows-сборщик с проверкой JDK/Android SDK и SHA-256 Gradle.
- Unit-тесты геометрии и GitHub Actions workflow для тестов и сборки.

## Сборка APK на Windows

1. Установите Android Studio и в SDK Manager выберите Android SDK Platform 36 и Android SDK Build-Tools.
2. Для сборки используйте JDK 17 или 21; скрипт автоматически попробует найти JBR Android Studio.
3. Запустите build-apk.bat в корне репозитория.
4. После успешной сборки получите dist/ClearGPS-debug.apk.

Первая сборка скачивает официальный Gradle 8.14.6 и зависимости. SHA-256 дистрибутива Gradle сверяется перед распаковкой.

## Архитектура и ограничения

OpenStreetMap используется только как картографическая основа и геометрия зоны, а не как источник координат. Отмеченная зона включает коррекционный режим риска, но не является самостоятельным доказательством радиоспуфинга. Если независимого источника нет, достоверные координаты гарантировать нельзя.

Wi-Fi fingerprints, BLE-маяки, cell positioning, сырые GNSS-измерения и полноценная sensor fusion пока не реализованы и являются следующими этапами.

Mock location требует явного выбора приложения в настройках разработчика Android. Некоторые приложения обнаруживают или игнорируют фиктивные координаты. Выдача отключена по умолчанию.

## OpenStreetMap

Используются растровые тайлы tile.openstreetmap.org и отображается атрибуция OpenStreetMap. Соблюдайте политику сервера тайлов: https://operations.osmfoundation.org/policies/tiles/
