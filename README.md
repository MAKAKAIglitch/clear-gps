# Clear GPS

Clear GPS — экспериментальное Android-приложение для выявления GNSS-аномалий и коррекции координат в пользовательских зонах риска.

## Уже включено в стартовую основу

- Интерфейс Jetpack Compose + Material 3 с динамическими цветами Android 12+, карточками статуса и явными состояниями сканирования.
- MapLibre Native и растровая карта OpenStreetMap; синяя точка реальной/расчётной позиции, визуальный радиус точности и отдельный янтарный ручной ориентир.
- Ручное рисование полигональной зоны риска, локальное сохранение и повторная отрисовка.
- Кнопка «Обновить источники»: получает системную позицию Android и сканирует доступные Wi‑Fi-точки, мобильные соты и Bluetooth LE-маяки.
- Первый прозрачный фильтр: скачки координат, неправдоподобная скорость, расхождение GNSS с сетевым местоположением и fallback.
- Foreground service с уведомлением для фонового мониторинга.
- Отдельный mock-location output, который выключен по умолчанию.
- Самонастраивающийся Windows-сборщик: поиск совместимой Java, SDK и Gradle; проверка SHA-256 скачиваемых архивов; резервные варианты при ошибке сети.
- Unit-тесты геометрии и GitHub Actions workflow для тестов и сборки.

## Сборка APK на Windows

Запустите **build-apk.bat** в корне репозитория. Не нужно вручную выставлять JAVA_HOME или устанавливать Gradle.

Сборщик последовательно:

1. Проверяет JAVA_HOME, Java в PATH, встроенный JBR Android Studio, распространённые папки JDK и записи реестра Windows. Несовместимая Java (например, Java 8) пропускается, а поиск продолжается.
2. Если подходящего JDK не найдено, скачивает Eclipse Temurin JDK 21 в %LOCALAPPDATA%\ClearGPS\tools\jdk-21 через API Adoptium и сверяет архив с опубликованным SHA-256. Администраторские права не нужны.
3. Ищет Android SDK по ANDROID_SDK_ROOT, ANDROID_HOME и стандартным каталогам. Если нужных компонентов нет, использует установленный sdkmanager; если менеджера нет — после подтверждения скачивает официальные Android command-line tools и проверяет их SHA-256.
4. После отдельного подтверждения устанавливает недостающие Android SDK Platform 36 и Build-Tools 36.0.0. Перед этим показывается ссылка на условия лицензии Android SDK; лицензии принимаются только после подтверждения пользователя.
5. Скачивает официальный Gradle 8.14.6 и проверяет его SHA-256. Если загрузка не получается, проверяет, не установлен ли точный Gradle 8.14.6 или не лежит ли он в стандартном Gradle-кеше.
6. Запускает unit-тесты и сборку debug APK.

После успешной сборки файл будет находиться здесь: **dist/ClearGPS-debug.apk**.

При первой настройке может потребоваться интернет и несколько сотен мегабайт свободного места. Автоматическое скачивание JDK или Android SDK не гарантируется при блокировке официальных серверов или отсутствии сети; в таком случае скрипт покажет этап и причину ошибки. Переменную CLEAR_GPS_NO_PAUSE=1 можно установить для запуска из другого скрипта без завершающей паузы.

## Архитектура и ограничения

OpenStreetMap используется только как картографическая основа и геометрия зоны, а не как источник координат. Отмеченная зона включает коррекционный режим риска, но не является самостоятельным доказательством радиоспуфинга. Если независимого источника нет, достоверные координаты гарантировать нельзя.

### Радиолокация и кэш

При явном согласии пользователя приложение может отправлять в BeaconDB идентификаторы и уровни сигнала доступных Wi‑Fi-точек, мобильных сот и BLE-маяков по HTTPS. SSID, IMEI, контакты и GPS-координаты устройства в запрос не входят. Идентификаторы радиоисточников и последняя оценка хранятся в приватных данных приложения; в настройках можно удалить кэш и отозвать согласие.

BeaconDB экспериментальная, покрытие неравномерное, а оценка может быть неточной. Полный публичный дамп базы для предзагрузки недоступен, поэтому приложение кэширует локально последний радиоснимок и оценку, а не пытается скачать всю базу. По кнопке обновления проводится новый скан; необязательная ежедневная задача повторно проверяет сохранённый снимок по сети. Из-за ограничений Android WorkManager запуск может происходить позже суток; фоновая задача не сканирует радиоэфир скрытно.

Android может ограничивать частоту Wi‑Fi-сканирования, не показывать некоторые мобильные соты и скрывать устройства с рандомизированными Bluetooth MAC-адресами. Наличие нескольких источников не гарантирует координаты: при слабом покрытии сервис может не вернуть оценку.

Радиооценка используется в качестве резервной позиции в GNSS-фильтре только если нет доступного системного fallback, она не старше 30 минут и её радиус точности не превышает 1 км. Ручной ориентир можно отдельно разрешить как самый последний fallback: он должен быть установлен не более 24 часов назад, помечается точностью ±1,5 км и не используется без явного включения этой опции. Сам по себе ручной ориентир не выдаётся другим приложениям; выдача возможна только при отдельном включении mock location.

Mock location требует явного выбора приложения в настройках разработчика Android. Некоторые приложения обнаруживают или игнорируют фиктивные координаты. Выдача отключена по умолчанию.
