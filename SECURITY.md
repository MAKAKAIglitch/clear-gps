# Security policy

Clear GPS is experimental software and does not guarantee detection of every GNSS spoofing, meaconing or jamming scenario.

Do not publish an exploit, private route, radio identifiers or sensitive diagnostic logs in a public issue. Use the repository's private vulnerability reporting feature in the Security tab when available. If private reporting is unavailable, contact the maintainer through the GitHub profile before sharing details publicly. The project does not currently promise a fixed response or patch SLA.

Reports should include the affected version, Android/device context, safe reproduction steps and redacted evidence. Relevant issues include coordinate publication without a trusted fix, private-data leakage, unsafe import parsing, unintended network submission, OBD write/control behaviour, privilege misuse and crashes from hostile inputs. RF transmissions are not required to report a software issue.
