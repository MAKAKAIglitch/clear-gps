This asset is used as the default offline airport catalogue. Clear GPS can
refresh a separate private cache from the public OurAirports daily CSV only
after the user enables the airport-catalogue network-consent switch.
The refresh is HTTPS GET and does not send the user's position or radio data.

Online source:
https://davidmegginson.github.io/ourairports-data/airports.csv
